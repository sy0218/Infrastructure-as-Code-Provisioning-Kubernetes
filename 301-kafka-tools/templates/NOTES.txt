[Kafka Tools 배포 완료]
Release: {{ .Release.Name }}
Chart  : {{ .Chart.Name }}-{{ .Chart.Version }}


[구성]
1. Schema Registry
   - Kafka 메시지의 데이터 형식(Schema)을 관리한다.
   - Deployment + Service로 실행된다.
   - 포트: {{ .Values.schemaRegistryPort }}

2. Kafka UI
   - Kafka의 Topic, 메시지, Consumer 등을 웹 화면에서 확인한다.
   - Deployment + Service + Ingress로 실행된다.
   - 접속: http://{{ .Values.kafkaUiHost }}

3. Kafka Exporter
   - Kafka의 상태/메트릭을 Prometheus가 수집할 수 있게 제공한다.
   - Deployment + Service로 실행된다.
   - 포트: {{ .Values.kafkaExporterPort }}

[배포 전제]
- 300-data-layer-base가 먼저 설치되어 있어야 한다.
- Kafka 접속 정보와 공용 ConfigMap/Secret을 여기서 제공한다.
- 필요한 설정이 없으면 Pod가 정상적으로 시작하지 못할 수 있다.


[Kafka UI 접속 주의]
- Kafka UI는 Ingress를 통해 접속한다.
- 포트를 직접 붙이지 않는다.

http://{{ .Values.kafkaUiHost }}

- 접속하는 PC에서 {{ .Values.kafkaUiHost }}가
  Ingress VIP로 해석되어야 한다.
- DNS 또는 /etc/hosts 설정이 필요할 수 있다.


[Kafka 주소 변경 시]
Kafka Broker 주소가 변경되면

1. 300-data-layer-base의 Kafka 설정
2. 이 차트의 kafkaBootstrap

두 곳을 같은 커밋에서 수정하고 helm upgrade 한다.
