[전제 — 수집 노드 라벨 (차트가 붙이지 않는다)]
kubectl label node <장비가 보내는 노드> {{ range $k, $v := .Values.tcpSocket.nodeSelector }}{{ $k }}={{ $v }}{{ end }}
→ 없으면 tcp-socket-collector 만 Pending

[확인]
kubectl -n {{ .Values.global.namespace }} get deploy -l app.kubernetes.io/part-of=data-layer | grep -E 'cdm-|tcp-socket'
kubectl -n {{ .Values.global.namespace }} get pod -l app=cdm-mapper -L cdm.mapper/module
kubectl -n {{ .Values.global.namespace }} get pod -l app=tcp-socket-collector -o wide
