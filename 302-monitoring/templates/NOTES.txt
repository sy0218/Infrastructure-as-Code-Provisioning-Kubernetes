[구성]
1. Alloy
   - DaemonSet → 모든 Node에 1개씩 실행
   - Node / Container 메트릭 수집
   - Prometheus로 전달

2. Prometheus
   - Deployment → 메트릭 수집 및 저장
   - Alloy / PostgreSQL / Kafka 등의 메트릭 수집
   - 접속: http://{{ .Values.global.hosts.prometheus }}

3. Grafana
   - Deployment → Prometheus 메트릭 시각화
   - 접속: http://{{ .Values.global.hosts.grafana }}


[전체 흐름]
Node / Container
      ↓

      ↓
  Prometheus
      ↑
PostgreSQL / Kafka
      ↓
   Grafana
      ↓
   Browser

[노드 배치]
Prometheus / Grafana 는 values.yaml 의 nodeNames 에 적힌 노드에만 뜬다. (nodeAffinity)

prometheus:
  nodeNames: ["ap"]   # 여러 개면 그중 한 곳 → replicas 1 이라 전부에 뜨는 게 아니다

- 배치 노드를 바꾸려면 이 목록만 고치고 helm upgrade → 매니페스트는 건드리지 않는다.
- 키를 지우면 고정이 풀린다. (스케줄러가 아무 노드나 고름)
- Alloy 는 대상이 아니다. DaemonSet 이라 모든 노드에 1개씩 뜨는 것이 목적이다.


[배포 전제]
- 300-data-layer-base가 먼저 설치되어 있어야 한다.
- Namespace / 공용 ConfigMap(data-layer-env) / Secret / RBAC을 제공한다.
- 수집·스크랩 설정은 300이 아니라 이 차트가 소유한다. (아래 [설정 변경])
- RBAC이 없으면 파드는 정상 기동한 채 /targets만 조용히 빈다.


[설정 변경]
설정 ConfigMap 3종을 이 차트가 소유한다 → helm upgrade 한 번으로 반영된다.

  alloy-config        (config.alloy)      → ds/alloy
  prometheus-config   (prometheus.yml)    → deploy/prometheus
  grafana-datasource  (datasource.yml)    → deploy/grafana

helm upgrade monitoring ./302-monitoring \
  -f values.common.yaml -n data-layer

- 파드 템플릿의 checksum 어노테이션이 ConfigMap 해시를 들고 있다.
  → 설정이 바뀌면 해시가 바뀌어 자동 롤아웃된다. 수동 rollout restart 불필요.
- Grafana 대시보드(JSON)만은 이미지에 구워져 있다.
  → 고치면 이미지 재빌드 + 새 태그가 필요하다. (build_and_push.sh <TAG> grafana)
- ConfigMap을 kubectl로 직접 수정하지 않는다. values 를 고쳐 helm upgrade 한다.


[확인]
kubectl -n {{ .Values.global.namespace }} get ds/alloy deploy/prometheus deploy/grafana
kubectl -n {{ .Values.global.namespace }} get cm alloy-config prometheus-config grafana-datasource
→ Prometheus /targets에서 모든 Target이 UP인지 확인

kubectl -n {{ .Values.global.namespace }} get pod -o wide -l app.kubernetes.io/part-of=data-layer
→ NODE 열이 nodeNames 와 일치하는지 확인


[삭제 시 주의]
- helm uninstall 시 Grafana / Prometheus PVC도 삭제된다.
- longhorn StorageClass 의 reclaimPolicy 가 Delete → PV 와 볼륨 실데이터까지 따라 지워진다.
- Grafana 대시보드와 Prometheus 저장 메트릭이 함께 삭제된다.
