[장애 원칙]
- 노드가 죽으면 그 노드의 브로커 파드는 다른 노드로 옮겨지지 않는다 (PV 가 그 노드에만 있다).
  Node 를 지운 뒤 재생성되는 파드는 Pending 에 멈춘다 — 쿠버네티스가 빈 디스크로 "복구"하지 않는다.
  남은 복제본(RF {{ .Values.kafka.replicationFactor }})이 서비스를 잇는다. 복구 절차는 README '노드 장애'.
- updateStrategy 가 OnDelete 라 설정/이미지 변경도 저절로 반영되지 않는다 → README '롤링 재기동'.


[배포 전제]
- Ansible kafka_prereq 로 nodes 표의 노드마다 {{ .Values.kafka.data.path }} / {{ .Values.kafka.metadata.path }} 가 만들어져 있을 것 (root:root 2770).
- 노드 포트 {{ .Values.kafka.ports.client }}/{{ .Values.kafka.ports.interBroker }}/{{ .Values.kafka.ports.controller }}/{{ .Values.kafka.ports.jmx }} 가 비어 있을 것 (hostNetwork).
- Harbor 에 kafka / schema-registry / kafka-ui / kafka-exporter 이미지가 push 되어 있을 것.
- 300-data-layer-base install (공용 ConfigMap 의 KAFKA_BOOTSTRAP = 위 내부 bootstrap).
