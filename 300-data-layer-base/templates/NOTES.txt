data-layer 공용 리소스 배포 완료
Release: {{ .Release.Name }}
Chart  : {{ .Chart.Name }}-{{ .Chart.Version }}

생성된 리소스
- Namespace          : {{ .Values.global.namespace }}
- ConfigMap          : data-layer-env
- Secret             : data-layer-secrets
- ClusterRoleBinding : {{ .Values.global.namespace }}-default-admin
  → default ServiceAccount에 cluster-admin 권한 부여

확인 방법
kubectl get ns {{ .Values.global.namespace }}
kubectl -n {{ .Values.global.namespace }} get cm data-layer-env secret data-layer-secrets

주의사항
- Kafka / MinIO / PostgreSQL / Neo4j는 이 차트에서 설치하지 않는다.
  → 기존에 설치된 서버의 주소와 ConfigMap 설정이 맞는지 확인한다.

- ConfigMap / Secret을 kubectl로 직접 수정하지 않는다.
  → values.yaml 수정 후 Helm upgrade 또는 ArgoCD Sync로 배포한다.
