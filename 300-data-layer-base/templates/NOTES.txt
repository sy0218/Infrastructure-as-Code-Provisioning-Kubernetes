     cluster-admin 권한 부여

  get cm/data-layer-env secret/data-layer-secrets

kubectl get clusterrolebinding \
  {{ .Values.global.namespace }}-default-admin


[배포 전제]
- data-layer 워크로드보다 먼저 배포한다.
- Kafka / MinIO / PostgreSQL / Neo4j는 이 Chart에서 설치하지 않는다.
  → Kafka 는 301-kafka(StatefulSet), PostgreSQL 은 303-postgres(CNPG), MinIO·Neo4j 는 노드 로컬(Ansible).
- 데이터 저장소의 접속 주소는 values.yaml(global.*)에서 관리한다.


[설정 변경]
- ConfigMap / Secret은 values.yaml을 통해 관리한다.
- 변경 후 Helm upgrade 또는 ArgoCD Sync로 반영한다.
- kubectl로 리소스를 직접 수정하지 않는다.
