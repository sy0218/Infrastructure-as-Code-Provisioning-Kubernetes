주의사항
- 103-cnpg(CRD/오퍼레이터)와 300-data-layer-base(네임스페이스)가 먼저 설치돼 있어야 한다.
  → CRD 가 없으면 install 이 "no matches for kind Cluster" 로 죽는다
    (helm template 은 CRD 검증을 안 해 통과한다 — 안심 금물).

- helm uninstall = Cluster CR 삭제 = 오퍼레이터가 파드·PVC 까지 지운다(데이터 소실).
  Database CR 삭제는 반대로 DB 를 지우지 않는다(retain).

- 계정값(secrets.*)은 300-data-layer-base 의 postgresUser/postgresPassword 와,
  DB 이름(databases.*)은 300 의 collectorDbName·icebergCatalogDbName 과
  같은 커밋에서만 함께 바꾼다.

- 클러스터 안 소비자 주소는 {{ .Values.clusterName }}-rw.{{ .Values.global.namespace }}.svc.cluster.local:5432,
  클러스터 밖(DBeaver 등)은 {{ .Values.externalIp }}:5432 다.
